# drydocc website

The source of [drydo.cc](https://drydo.cc), the website of
[drydocc](https://github.com/hiemalis-at/drydocc) - Infrastructure as Markdown
for AI coding agents.

`www/` is the site as it is served: plain HTML, ES modules, Alpine.js and
Tailwind CSS, with no build step. GitHub Pages deploys it on every push to
`main`.

This repository is release-only. Each release publishes one snapshot commit,
tags it, and creates a GitHub Release with its notes. Issues and proposals for
the site are welcome here; changes land through the next release.
