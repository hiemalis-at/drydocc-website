The example five boxes · one tailnet

Five boxes that grew over the years, not by design

This walkthrough follows one example setup - the kind most homelabs and small offices really are: a rented vServer, a legacy desktop under the desk, two Raspberry Pi 3s that have run untouched for years (one of them still 32-bit), and a Pi 4 on Home Assistant OS, where you can't install anything at all.

Tailscale is the way in. No reverse proxy, no port forwarding, no public certificate. The one box with a public IP exposes key-only SSH on a non-standard port - and nothing else.

Six acts

From a bare box to a full rebuild - by writing markdown

Each act runs one skill: a markdown recipe your agent follows, backed by Python and shell scripts. Copy the command into your agent - every run leaves a journal entry in your repo.

  • Test runs - /lab run <scenario>: a headless agent works through a scenario on fresh VMs, and only assertions decide whether it passed. Repeat it for a pass rate.
  • Prototypes - /lab up: build a node with your agent, keep good states as restore points, and roll back mistakes. Then extract a runbook; the lab replays it on a fresh VM, and only a verified runbook is promoted into your fork.
